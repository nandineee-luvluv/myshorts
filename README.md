# GTA VI Clipper Max — promo videos

Three vertical promo videos in different visual styles for the
`gta-iv-clipper-max` live-stream clipper:

| Video | Style |
| --- | --- |
| `01-terminal-noir.mp4` | Dark terminal / system dashboard |
| `02-neon-arcade.mp4` | Neon arcade |
| `03-clean-editorial.mp4` | Minimal editorial |

Each MP4 is 720×1280, H.264, silent, and includes its message as on-screen
text. The matching `.srt` file is provided for subtitle/caption workflows.
These are original graphic promos; they do not contain GTA gameplay footage,
music, or third-party creator content.

The promos advertise features of the clipper and accurately note that its
source repository is currently private. This public repository contains only
the promotional videos and caption files.
